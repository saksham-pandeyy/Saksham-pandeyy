### About Me

Full-stack software engineer architecting **scalable web platforms**, **cross-platform mobile applications**, and **agentic AI systems**. Specialized in modern TypeScript ecosystems by combining Next.js frontends, React Native mobile clients, and Node.js backend services with local data synchronization and structured LLM tool-calling pipelines.

Focused on shipping clean, well-architected code designed for production reliability, long-term maintainability, and high-impact user experiences across global products.
